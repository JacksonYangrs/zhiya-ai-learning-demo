变动成本是怎么算出来的？

变动成本 = 用一次花一次的钱。学生每扫一次作业，我们就给 AI 公司付一次钱（VLM 看图 + LLM 分析）。用得多付得多，不扫不付——就像打车按里程计费，不是包月。

付费用户（无限扫）年变动成本 ≈ ¥108，按你定的假设一步步算：

  • VLM 看图单价：¥0.03 / 张
  • 每天扫描会话：3 次（你说的 100% DAU，天天用）
  • 每次会话页数：2 张（多页连扫，一次扫三张也常见）
  • 扫错 / 重扫系数：×1.25（手抖、拍糊、识别失败要重来）
  • → 每人每年图片数 = 3 × 2 × 1.25 × 365 ≈ 2,737 张
  • VLM 费用 ≈ 2,737 × ¥0.03 ≈ ¥82
  • LLM 诊断 / 题组 / 周报 ≈ ¥26
  • 合计 ≈ ¥108 / 付费用户 / 年

免费用户（限流）：轻量使用，约 ¥20 / 年。

变动总成本 = 付费用户 × Vp ＋ 免费用户 × Vf

打开上方「自部署 VLM」开关，VLM 单价砍到约 28%，付费用户变动成本从 ¥108 降到 ≈ ¥30——这就是架构里"核心环节迁自部署"的财务意义。

自部署大模型，成本怎么砍到约 28%？

第三方按张收费，自部署改成"包月服务器"。学生每扫一张作业，VLM 厂商（通义/智谱/OpenAI 这类）就按张收 ¥0.03，LLM 分析诊断另算——用得多付得多，像打车按里程。到规模后，自己租 GPU 跑开源视觉模型（Qwen-VL / InternVL 这类），不再按张给厂商付钱。

单位成本为什么能降到约 28%？

  • VLM 单张图：第三方 ¥0.03 → 自有算力摊薄后 ≈ ¥0.0084（×28%）
  • LLM 诊断 / 题组 / 周报：同理迁到自托管，单位成本同比例下降
  • 前提：流量够大、服务器摊得薄；小用户时第三方反而更划算
